# Numbers and Bases

Base prefixes change how an integer is written. They do not change the value.

<!-- dewy-example: {"mode": "run", "stdout": "42 42\n"} -->
```dewy
let binary:int64 = 0b101010
let hex:int64 = 0x2a
printl"{binary} {hex}"
```

The [reference](/reference/literals.html) has the complete rules.
