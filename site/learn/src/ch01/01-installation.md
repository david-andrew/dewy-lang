# Installation

Use the [installation guide](/install/) for Linux x86-64/ARM64, macOS ARM64 and Windows x64, prerequisites, verification and rollback.

```sh
curl -fsSL https://dewy-lang.org/install.sh | bash
```

On PowerShell:

```powershell
irm https://dewy-lang.org/install.ps1 | iex
```

A checkout can use `./tools/dewy` directly; it requires Python, a C compiler and make for its first build. The standalone download needs no Python.
