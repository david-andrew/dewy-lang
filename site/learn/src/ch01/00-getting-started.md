# Getting Started

Dewy is still in its early development stages, but the compiler is usable. This
chapter explains how to install the current toolchain on Linux x86-64, run the
Python-hosted Dewy compiler, and write a first program.

The [browser playground](../../playground/) currently supports µDewy, the
bootstrap subset, rather than full Dewy. Broader installers and a browser-hosted
Dewy compiler remain future work.
