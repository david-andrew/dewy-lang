# Hello, Many Worlds!

This chapter contains short example programs over a variety of different domains--basically a *Hello World* for each problem. Each of these should serve as a quick start guide for common tasks in Dewy.

> These are design targets, not a claim that every domain library is available
> today. Check each page and the implementation status before expecting an
> example to compile with the current toolchain.

- [GUI](01-gui.md): creating a window with a click counter
- [Graphics](02-graphics.md): drawing a triangle from scratch
- [Audio](03-audio.md): playing a sine wave through the speakers
- [Networking](04-networking.md): building a simple client/server chat program
- [2D Game Development](05a-game-development.md): making a 2D Flappy Bird clone
- [3D Game Development](05b-game-development.md): making a 3D racing game
- [Web Development](06-web-development.md): building a simple website
- [Databases](07-databases.md): creating a simple data store
- [Cryptography](08-cryptography.md): encrypting and decrypting a string
- [Operating Systems](09-operating-systems.md): running Hello World on bare metal
- [Compilers](10-compilers.md): building a toy compiler
- [Scientific Computing](11-scientific-computing.md): making an infinitely zooming Mandelbrot set
- [Robotics](12-robotics.md): forward and inverse kinematics of a 6-DoF robot arm
- [Machine Learning](13-machine-learning.md): training a simple MLP on MNIST
