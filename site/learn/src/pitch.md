# Dewy at a Glance

Ordinary computation should read clearly. Dewy brings values, typed functions, containers and engineering quantities into one language.

<!-- dewy-example: {"mode": "run", "stdout": "42\n"} -->
```dewy
let values = [20 22]
printl(values[0]+values[1])
```

Try the [compiled browser examples](/playground/) or follow the [core-language lessons](ch03/expressions-statements-blocks.md). The language goals are a direction, not a performance claim: see [GOALS](https://github.com/david-andrew/dewy-lang/blob/master/docs/GOALS.md).
