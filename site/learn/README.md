# Learning Dewy

The published chapters in `src/SUMMARY.md` teach current compiler examples.
Every Dewy fence declares check/run/reject/design-only metadata; see
[the site builder](../README.md). Design boundaries link to the normative
reference and generated coverage. Unpublished drafts live in the archive.

Build the complete site with `python3 site/scripts/build.py` from the repository
root. Do not commit `book/` or `site/dist/`.
