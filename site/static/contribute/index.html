Set up the checkout

git clone https://github.com/david-andrew/dewy-lang
cd dewy-lang
uv sync
python3 -m tools.core test --quick -n 2
python3 -m tools.core test -n 2

Use Python, a C compiler, make and Node. See DEVELOPMENT for platform prerequisites, bootstrap and fixed-point checks.

Find the code

  • compiler/: frontend, checking, lowering and code generation in Jo.
  • lib/: standard, platform and game libraries.
  • stage0/ and bootstrap/: independent C seed and frontend.
  • tests/cases/: focused golden programs; tests/ladder/: acceptance programs.
  • tools/: build, test, fuzz and package commands.
  • site/ and editors/vscode/: website and editor.

Make a focused change

Give the task acceptance criteria, owned files, non-goals and a budget. Add simple language behavior as its own golden case; use pytest for multi-file and tooling checks. Run the relevant tests and quick suite for compiler/library changes, then the full batch gates before merging. Keep generated coverage and timing output out of Git.
