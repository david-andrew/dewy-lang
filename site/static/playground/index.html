Play and run

Play games written in Dewy, or run small programs and compare their output. Everything here was compiled to WebAssembly by this site’s build.

About this playground

This page runs programs compiled ahead of time; it does not compile your edits yet. Install Dewy to change them: every game builds natively with dewy FILE.dewy and for the browser with --target wasm32. Status lists what this build checked: exact output under Node for the terminal programs, and a compile and WebAssembly build for each game.
