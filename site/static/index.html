Dewy

An Everyday Language

Dewy is a language for clear, expressive computation—useful for anything from ordinary programming to complex engineering, science, and mathematics, and everything in between.

$ curl -fsSL https://dewy-lang.org/install.sh | bash

text = "café 👨‍👩‍👧‍👦 🍀"

loop i in 0.. and c in text
    if c not =? ' ' {
        printl"{i}: {c}"
    }

The compiler builds native executables and WebAssembly. It is written in Sloppy for now; Dewy will compile itself later. The browser playground runs precompiled examples, and Status lists what the compiler passes today.

Key Features

Capabilities at the heart of Dewy’s design. Every example on this page is compiled and run with the current compiler on each site build.

units.dewytested ✓
from units import kg, m, N, J, W

# Units are values. Juxtaposition multiplies.
mass = 10kg
velocity = 30m/s
energy = 1/2 * mass * velocity^2   # 4500 J

force = 1000kg * 9.8(m/s^2)        # 9800 N
work = 20N * 10m                   # 200 J
power = work / 4s                  # 50 W

printl"{energy/J} J  {force/N} N  {power/W} W"
engineering & science

Physical units, built in

Dewy treats kilograms, meters, and seconds as values with dimensions, not as plain numbers. Juxtaposing a number with a unit multiplies them, dimensions carry through arithmetic, and mismatched dimensions are errors—so 20N * 10m is joules and 3m + 5s doesn’t compile. Dimensions are checked at compile time and cost nothing at runtime.

ranges.dewytested ✓
# Bounds are visible: [ ] includes, ( ) excludes.
window = [0..10)              # 0 1 ... 9
evens = 0,2..100              # step inferred from the pair
countdown = [10,8..0]         # negative steps too

printl(16 in? (5..15])        # false

# Slices use the same bounds.
samples = [3 1 4 1 5 9 2 6]
printl(samples[end-3..])      # [5 9 2 6]
printl('hello world'[0..5))   # hello
ranges

Ranges with clear bounds

Brackets say exactly which endpoints belong to a range, a second anchor sets the step—including negative steps—and the same bound forms drive loops, membership tests, and slicing.

loops.dewytested ✓
ratings = [
    'star wars' -> 73
    'star trek' -> 89
    'legend of the galactic heroes' -> 100
]

# One keyword covers while, for, and beyond.
loop [show rating] in ratings
    printl'I give {show} a {rating} out of 100'

# Iterators compose logically.
loop i in 0.. and letter in 'Dewy' printl'{i}: {letter}'
iteration

One loop to rule them all

There is no for / while / do-while zoo—loop takes any condition. The in operator assigns the next value and reports whether one existed, so iterators can combine with and or or in a single loop.

numbers.dewytested ✓
# Integers grow as needed instead of overflowing.
big = 2^100
printl(big)

# Dividing integers gives an exact fraction.
third = 1/3
printl(third + 1/6)       # 1/2

# Decimal literals are exact too.
printl(0.1 + 0.2 =? 0.3)  # true
numbers

Exact by default

int is the mathematical integer: word-sized while the value fits, big when it doesn’t, and never silently wrapped. Dividing integers gives a rational that prints as the fraction it is, and decimal literals are exact fractions unless a float is asked for. Floats are strict IEEE 754 when you want them.

refinements.dewytested ✓
# A type can carry a condition on its values.
Positive:type = int64<(>? 0)>
NonEmpty:type = array<int64 length >? 0>

first = (xs:NonEmpty):>int64 => xs[0]
span = (a:int64 b:int64<(>=? a)>):>int64 => b - a
share = (total:int64 n:Positive):>int64 => total // n

printl(first([3 5 8]))    # 3
printl(span(3 10))        # 7
printl(share(84 2))       # 42

# first([]) and share(84 0) are compile errors.
type system

Types that carry useful facts

Refinements let a type say “positive integer” or “non-empty array”. The compiler proves each condition from literals and ordinary control flow—a guard, a store, a loop range—and rejects a call that provably breaks one. A proven fact also removes work: xs[0] on a non-empty array needs no bounds check. Refinements cover integer ranges, array and string lengths, and record fields.

safety.dewytested ✓
xs = [3 1 4 1 5]

# The loop range proves every index is in bounds.
total = 0
loop i in [0..xs.length) total += xs[i]
printl(total)             # 14

# When an index can't be proven, ask for a value.
printl(xs.get(9))         # none
printl(xs.get(2))         # 4
safety

No traps behind your back

Indexing, division and narrowing can fail, so Dewy’s rule is that each is proven from facts the compiler can see, handled as a value (xs.get(i) is int64 | none), or checked explicitly. Where the compiler can’t yet prove one, today’s compiler still inserts a runtime check that stops the program with a report. Turning those into compile errors with fix-its is under way. See what that adds up to in Safer than Rust.

functions.dewytested ✓
# `&` combines implementations into one overload set.
format = ((value:int64):>string => "integer: {value}")
       & ((value:string):>string => "text: {value}")

printl(format(42))      # integer: 42
printl(format("Dewy"))  # text: Dewy

# `@` passes a function without calling it.
double = (x:int64):>int64 => x * 2
twice = (f:<(x:int64):>int64> x:int64) => f(f(x))
printl(twice(@double 10))   # 40
functions

Functions are ordinary values

Function literals are expressions like any other: pass them, store them, and combine them. The & operator merges two implementations into one overload set, and each call selects the implementation whose parameter type matches the argument. @double names the function itself, ready to pass along.

objects.dewytested ✓
counter = (start=0) => [
    value = start
    increment = () => (value += 1)
]

# make a new counter object
count = counter(40)

# called on access
count.increment
count.increment

printl"count is {count.value}"
objects

Objects, blocks, and functions are one thing

Dewy’s syntax is deliberately unified: functions can construct structural objects, members can capture their siblings, and accessing a zero-argument function member calls it. Fields and behavior live together without separate class machinery, and a member that updates its siblings changes the object it is called on.
