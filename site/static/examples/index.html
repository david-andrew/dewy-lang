A whole game, start to finish

Paddle is the smallest game here. Its model is plain Dewy with no graphics dependency:

# A small deterministic game model, independent of drawing and input APIs.
Point:type = [x:float64 y:float64]
World:type = [position:Point velocity:Point paddle:float64 score:int64 misses:int64]

fresh = ():>World => World[Point[640.0 220.0] Point[180.0 240.0] 640.0 0 0]

advance = (@world:World dt:float64 pointer:float64):>void => {
    world.paddle = min(max(pointer 80.0) 1200.0)
    let before = world.position.y
    world.position.x += world.velocity.x*dt
    world.position.y += world.velocity.y*dt
    if world.position.x <? 20.0 {
        world.position.x = 20.0
        world.velocity.x = abs(world.velocity.x)
    }
    if world.position.x >? 1260.0 {
        world.position.x = 1260.0
        world.velocity.x = 0.0-abs(world.velocity.x)
    }
    if world.position.y <? 110.0 {
        world.position.y = 110.0
        world.velocity.y = abs(world.velocity.y)
    }
    if before <? 620.0 and world.position.y >=? 620.0 and abs(world.position.x-world.paddle) <? 92.0 {
        world.position.y = 620.0
        world.velocity.y = 0.0-abs(world.velocity.y)-8.0
        world.velocity.x = (world.position.x-world.paddle)*4.0
        world.score += 1
    }
    if world.position.y >? 760.0 {
        world.position = Point[640.0 220.0]
        world.velocity = Point[180.0 240.0]
        world.misses += 1
    }
}

The game file draws the model and feeds it the pointer. The platform library supplies the window, input, font, renderer and frame loop, natively and on the web:

# Build with the experimental source core. The platform library supplies
# the window, input, font, renderer, frame loop, and native/web backends.
from p"paddle_model.dewy" import fresh, advance

let world = fresh

update = (dt:float64):>void => {
    advance(@world min(dt 0.05) mouse_pos().x)
}

draw = ():>void => {
    clear(rgb(0.025 0.045 0.08))
    rect(20.0 100.0 1240.0 2.0 rgb(0.15 0.25 0.35))
    rect(20.0 660.0 1240.0 2.0 rgb(0.15 0.25 0.35))
    circle(vec2(world.position.x world.position.y) 12.0 rgb(1.0 0.7 0.3))
    rect(world.paddle-80.0 632.0 160.0 12.0 rgb(0.3 0.9 0.8))
    text("DEWY / PADDLE" vec2(32.0 24.0) 32.0 rgb(0.85 0.95 1.0))
    text("Move the mouse to keep the ball in play" vec2(32.0 68.0) 18.0 rgb(0.5 0.65 0.75))
    text("Returns: {world.score}    Misses: {world.misses}" vec2(820.0 35.0) 22.0 rgb(0.3 0.9 0.8))
}

Because the model is separate, its behaviour is tested without opening a window. dewy test examples/paddle_tests.dewy runs these; add bounce to run only the matching test.

# Run: tools/dewy test examples/paddle_tests.dewy
# Filter: tools/dewy test examples/paddle_tests.dewy bounce
from p"paddle_model.dewy" import fresh, advance

$test
fresh_world = () => {
    let world = fresh
    $expect world.score =? 0 and world.misses =? 0
    $expect world.position.x =? 640.0
}

$test
side_wall_bounce = () => {
    let world = fresh
    world.position.x = 1259.0
    advance(@world 0.1 640.0)
    $expect world.position.x =? 1260.0
    $expect world.velocity.x <? 0.0
}

$test
miss_resets_the_ball = () => {
    let world = fresh
    world.position.y = 759.0
    advance(@world 0.1 80.0)
    $expect world.misses =? 1 and world.score =? 0
    $expect world.position.x =? 640.0 and world.position.y =? 220.0
}

Programs and libraries

Terminal programs and library demonstrations. From a checkout, run any of them with ./tools/dewy examples/NAME.dewy; several also run in the playground.

  • Language tour

    Arrays, records, generics, strings and optionals in 35 lines, each printing a checked result.

  • Generators

    Infinite sequences, multi-value steps, composable adapters and a recursive tree walk with lazy.

  • Entities and events

    The bundled Pool<T> and Heap<T>: stable handles, a priority queue of damage events, and a copied world that stays independent.

  • A generic ring buffer

    A bounded history built on ring.dewy, a generic container written entirely in Dewy with its own indexing protocol.

  • Exact integers

    100!, binomial coefficients, signed floor division and 2^256, exact on native and web.

  • Exact fractions

    Harmonic sums and dice probabilities as reduced fractions.

  • Fitting a trajectory

    Least squares with matrices, transpose and a linear solver; its test blocks check the fit.

  • Parallel particles

    Particle forces through the worker pool, checked value by value against the serial simulation.

  • GPU height field

    One fused array expression runs on the GPU when there is one, and is compared with the same function on the CPU.

  • Time intervals

    Instants, half-open ranges, interval difference and overlap on a nanosecond grid.

  • Typed settings files

    Load JSON into a record with defaults, update a copy, and save a full-width integer without rounding.

  • Structured cancellation

    A task group whose Ctrl-C listener cancels the batch; without an interrupt it joins normally.

  • Network pong

    A two-player game with invite screens; a browser build can join a native host.

Acceptance programs

The compiler is measured against an acceptance ladder of 147 programs, from word counting to a Dewy frontend; all 147 pass, and one more waits on an open design question. Seven flagship programs of one to five thousand lines each also pass. A few to read:

  • A Dewy frontend: the compiler’s own lexer and Pratt expression parser, ported to Dewy
  • Bytecode VM: a stack machine whose faults are error values
  • Regex engine: Thompson-style state sets for literals, dot and star
  • SHA-256: the hash on explicitly wrapping 32-bit words
  • JSON round trip: a typed record to JSON and back, keeping a full 64-bit integer
  • Dijkstra: shortest paths with a priority queue
  • Calculator interpreter: a lexer with columns, a precedence-climbing parser and a tree-walking evaluator
  • Timetable solver: rooms, periods, teachers and enrollments into a school timetable

Start your own

dewy new writes a starting point with a README. The game templates are complete, playable programs with menus, sound and tests, and run natively or in a browser:

dewy new hello-app program     # a terminal program
dewy new gold-rush arcade      # a collect-and-dodge game
dewy new coin-race online      # a multiplayer game with rollback and invites
dewy watch gold-rush/gold-rush.dewy  # edits reach the running game

Other templates: platformer, 3d and story. Your first Dewy program walks through the basics.
