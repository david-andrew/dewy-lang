Install

Run Dewy on your machine.

The packaged installation currently supports Linux x86-64. It installs a native µDewy bootstrap compiler and the Python-hosted Dewy compiler.

Install the current toolchain

Early software: inspect the installer before running it in an environment you care about. Dewy has not reached a stable release.
shell
curl -fsSL https://raw.githubusercontent.com/david-andrew/dewy-lang/master/install.sh | bash

The installer writes to ~/.dewy and offers to add that directory to your shell path. Dewy locates Python 3.12 or newer on first use and remembers the compatible interpreter.

dewy hello.dewy
udewy hello.udewy

Run from a checkout

git clone https://github.com/david-andrew/dewy-lang.git
cd dewy-lang
python -m dewy dewy/tests/hello.dewy
python -m udewy udewy/tests/test_hello.udewy

The compiler writes intermediate source and target artifacts under __dewycache__/. Use -c to compile without running, and --target to select a µDewy backend.

Targets and present limits

  • Dewy installerLinux x86-64
  • µDewy backendsx86-64 Linux, WebAssembly, RISC-V, AArch64, and C
  • Dewy console I/Oprint and printl currently use Linux x86-64 syscalls
  • StabilityDevelopment version; syntax and semantics can change
