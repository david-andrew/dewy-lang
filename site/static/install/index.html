The Dewy programming language

Install Dewy

Use a standalone compiler and its matching libraries. Python is only needed for checkout development.

Development channel

Downloads are selected by a published toolchain channel. Website source and downloadable release revisions are separate; inspect their identities. Until a complete current release is published, use the checkout instructions below.

Linux and macOS

Supported toolchain hosts: Linux x86-64, Linux ARM64 and macOS ARM64. Require Bash, curl, tar and sha256sum (or shasum on macOS). Linux ARM64 uses aarch64 names in system tools.

curl -fsSL https://dewy-lang.org/install.sh | bash

Windows x64

Use PowerShell with Invoke-RestMethod, Get-FileHash and tar available. The installer updates your user PATH; it does not need a machine policy change.

irm https://dewy-lang.org/install.ps1 | iex

Verify the installation

dewy --version
dewy-core --print-lib
dewy check hello.dewy
dewy hello.dewy

Create hello.dewy with:

printl"Hello, Dewy!"

The final command prints Hello, Dewy!. The installer reports the immutable release identity; keep it when reporting a problem.

Update and rollback

dewy update
dewy rollback

The new installer stages and verifies a complete toolchain before switching the active compiler. Rollback returns to the saved previous generation. To select an immutable release, download the installer and pass --release TAG. Use --prefix PATH or --no-modify-path for a custom location or shell setup.

Build from source

On Linux x86-64, install Python, a C compiler and make. Clone the repository, then run:

git clone https://github.com/david-andrew/dewy-lang
cd dewy-lang
./tools/dewy examples/tour.dewy

The launcher builds from C on first use. For standalone builds and other host targets, see development instructions.

Migrating an older install

The new installation uses ~/.dewy/bin ahead of the legacy root PATH entry. Keep legacy executables and libraries until your projects have migrated. µDewy is retired; the new channel does not promise compatibility with archived programs. Find historical sources and releases.
