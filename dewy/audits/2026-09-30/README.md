# September 30 audit probe record

These sources and observations support [the audit](../../AUDIT_2026_09_30.md)
and its [roadmap follow-through](../../ROADMAP.md#focused-audit-follow-through-2026-09-30).
They are dated evidence and bounded reproducers, not a permanent test suite or
certification of later compiler revisions.

The original pass inspected `7dcf76726b23`; the focused pass used source at
`4870a21ae711d27f446b9169ee4773f4f2bd08d6` and an existing generation-three native
pair. Development subsequently amended that source revision to `7e22c065`.
[Native metadata](observations/native_metadata.json) preserves the binary hashes.
No compiler generation or full test suite was built for the audit. Default-prelude
native probes reused a private copy of a checked-prelude cache to limit machine
load; this supplies no evidence for uncached throughput. The compiler archive,
binaries and caches are omitted. Temporary paths in observations are replaced
with `<probe-output>`; counts, diagnostics, operation bodies and hashes are retained.

## Rerunning the hosted probes

Use the project's Python environment with the desired checkout on `PYTHONPATH`.
Each of the six hosted probes requires a scratch output directory and refuses to write
inside this recorded bundle. Run serially with a short timeout and low scheduling
priority. For example, from the repository root:

```sh
audit_repo=$(git rev-parse --show-toplevel)
audit_scratch=$(mktemp -d /tmp/dewy-audit-rerun.XXXXXX)
PYTHONPATH="$audit_repo" PYTHONDONTWRITEBYTECODE=1 timeout 15s nice -n 19 \
  "$audit_repo/.venv/bin/python" \
  "$audit_repo/dewy/audits/2026-09-30/probes/inference.py" \
  --output-dir "$audit_scratch/inference"
```

The other hosted scripts accept the same argument:

- `probe.py`: original DNF/generic kernel. Growing recursion is deliberately
  contained at Python recursion limit 220; that is not a Dewy execution policy.
- `layout_and_codegen.py`: original storage/key/leaf-code kernel.
- `source_probes.py`: accepted-source DNF and helper-guard cases, with a harness
  guard before large distribution.
- `cache_decision.py`: stubbed cache-hit decisions only.
- `specialization.py`: bounded 3/5/7 length-pair kernel, generating Dewy and
  textual µDewy sources along with observations.

Reruns write new observations; do not overwrite the historical JSON when
implementation changes alter a result. Scripts use private compiler APIs and
may require adaptation after those APIs change. The original bare no-prelude
directives are normalized to the explicit `$no_prelude=true` setting for current
module metadata parsing; workload bodies and bounded sizes are retained.
No script invokes a native
compiler rebuild or automatically expands the workload beyond the recorded sizes.

## Native reproductions

`cases/representation/` contains the six default-prelude value/layout programs.
`cases/inference/` contains the seven default-prelude cases and the no-prelude
monomorphic/generic tag pair. `cases/modules/` contains the four no-prelude
programs and their two imported modules. Use a matched existing Dewy/µDewy pair
and library sources, compiling in a fresh scratch working directory. A
default-prelude case can require a cold prelude check; run only when machine
resources permit. For example, after setting `audit_dewy`, `audit_udewy` and
`audit_library` to that pair's paths:

```sh
(
  cd "$audit_scratch"
  DEWY_LIBRARY_ROOT="$audit_library" DEWY_UDEWY="$audit_udewy" \
    timeout 18s nice -n 19 "$audit_dewy" \
    "$audit_repo/dewy/audits/2026-09-30/cases/representation/family_array_snapshot.dewy"
)
```

Successful representation and module programs return process status **42**;
the positive inference programs return **1**. These intentional nonzero results
are distinct from compilation failure. The recorded JSON keeps compile and run
statuses separate.

For native specialization, `specialization.py` generates the two audited source
sizes. Remove their `$no_prelude=true` line to reproduce the default-prelude
native runs. If compilation retains the UBC2 artifacts, the decoder can record
their operation groups without another compilation:

```sh
PYTHONPATH="$audit_repo" PYTHONDONTWRITEBYTECODE=1 timeout 10s nice -n 19 \
  "$audit_repo/.venv/bin/python" \
  "$audit_repo/dewy/audits/2026-09-30/probes/stream_variants.py" \
  --ubc-3 /path/to/three-lengths.ubc --ubc-7 /path/to/seven-lengths.ubc \
  --output "$audit_scratch/stream_variants.json"
```

Its recording backend groups identical operation sequences for two-parameter
functions. Compare the captured bodies as well as group size; the largest group
heuristic alone does not establish semantic equivalence for arbitrary programs.
