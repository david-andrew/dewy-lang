# Origin

The compiler (`compiler/`, `lib/`, `stage0/`), parts of the tooling and some
examples were forked from the Sloppy language at
commit `235e19a271bccad3fe72e36d03264807a632dc1b`, with a few later upstream
changes adapted selectively. Sloppy is MIT licensed: see `LICENSE` and `NOTICE`
here, and `lib/game/assets/OFL.txt` for the included font.

Dewy owns this fork. There is no upstream tracking; the code evolves for Dewy
and is meant to be replaced by a compiler written in Dewy.
