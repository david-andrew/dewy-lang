# Dogfood, round 11

Grades are obvious, discoverable, concise, safe, complete. Paper only. Go's select cases and Tokio's biased branches are the compact source-sensitive baseline. Dewy's drain, race, and within match them on cleanup. The source pattern takes more discovery than a branch tied to one operation. Python, TypeScript, and Swift need more adapter code for the same cancel and join.

A member that holds a type is not a cost. Negative fixtures are not in the floor.
