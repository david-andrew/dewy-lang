# Dogfood round 6: honest grades after revision

Recommendation: uniform block-end observable cleanup; a required `or_throw` on an inner owning scope/body with a fallible local continuation; narrow non-failing defer for one-off exit actions. **Floor: 3.** This is not ready to be advertised as an all-5 design. It is ready to discuss with David with the remaining costs visible.

This is one author's paper dogfood/review, not independent readers, user testing, compilation, benchmark evidence, or language implementer endorsement. All 19 programs contain enclosing functions. The numerical grades apply to Dewy's best shown form under the proposed rules and stated library contracts, not to intentionally broken before-versions. Negative versions reveal remaining traps during maintenance. Peer-language comparisons are reasoned alternatives, not invented numerical user-study scores.

## Scale and method

O/D/C/S/K = obvious / discoverable / concise / safe by default / complete.

- **5:** meets this scenario cleanly; no material cleanup-specific gap within its explicit assumptions.
- **4:** works with one real convention, extra boundary, or limited integration gap.
- **3:** substantial teaching cost, required manual protocol, or incomplete important case.
- **2:** a central requirement cannot be expressed reliably on the proposed surface.
- **1:** fails the requirement or defaults to a destructive result.

Obviousness is what a reader infers from source, not what a hover can explain afterward. Discoverability counts fix-its but not imaginary inference of arbitrary protocol intent. Safety counts forgetting a necessary manual step; it does not pretend every foreign runtime or concurrent external writer is in scope. Completeness is design completeness for the printed scenario, not shipped implementation. Thus a 5 for a fully specified ownership scenario does not mean a stub library exists. Ordinary recursion limits are held equal across languages.

Each row below cites the actual `.dewy` lines for **every score below 5**. Full source links identify the numbered file; line ranges are one-based. The one all-5 row has separate evidence for all five dimensions. Revisions were made before fixing these grades; unresolved costs were not erased by prose.

Python and TypeScript are competitive on local recovery in 12: they can catch outside their managed region without creating a helper. That is a genuine cost of keeping Dewy's failed cleanup as the function result. Rust offers strong lexical ownership but cannot be credited with automatically returning destructor errors. Go makes the exit action obvious at registration but its function-level defer is not Dewy's iteration-level cleanup. Swift's explicit defer is the fair region comparison; no universal lexical ARC-destructor guarantee is assumed. These distinctions, with primary-source links, are documented in [round6.md](round6.md), section 2.

For 13 the functional rewrite is ordinary in every peer language; it is not a unique Dewy advantage. For 14 result capture is particularly natural where failure is already a value; languages using thrown exceptions need a Result wrapper or a finally path to obtain the same all-outcomes behavior. For 15–17, keeping defer buys local expression of an obligation already present in the problem; it does not eliminate forgetting to register that obligation. External ownership/synchronization contracts remain necessary in every language.

## Iterations performed and why remaining scores stay below 5

1. **Timing comparison:** included two opposite socket protocols and retained the Spsc regression instead of presenting only lexical-region wins. Counted common per-iteration/parallel/move cases as ties. The recommendation now admits a raw-count tie and a weak severity advantage; no fabricated frequency evidence.
2. **Functional steelman:** replaced mutable indentation with a depth parameter and rewrote timing as capture/log/forward, including cancellation. Many early returns got a real helper rewrite, not a claim that removal was impossible.
3. **Visible exits:** narrowed a blanket loop scan into a scope-local completion acknowledgement. Added labeled break, explicit return exemption, consumed-before-jump recovery, unscoped parallel and collector programs. That improves safety but introduces special suffix semantics; O3 remains earned.
4. **External-state code:** made mutable editor access explicit with an `@` parameter; restore the saved value rather than false. Kept task confinement as a requirement. These changes cannot make an omitted defer statically detectable.
5. **Foreign example:** removed an unnecessary helper; defer-before-locals restores the flag before unlocking in the same function. No unverified claim about actual C annotations, foreign longjmp, or global synchronization was promoted to safety 5.
6. **Scope/cancellation honesty:** did not reintroduce R5's settled-looking two-field error wrapper when D40 Q3 is reopened. This leaves recovery K3 rather than inventing a new combined-error API outside the brief.

The project standard says weak cases should iterate before reaching open_decisions.md. This packet has iterated but still has material 3s; **do not copy it there as a dogfooded all-5 approval package**. A decision on timing and tolerance for a scope-level rather than jump-line marker is useful now; a declaration that the design has no remaining ergonomic gaps would be false. No names were cold-tested and no new spelling is claimed approved.
