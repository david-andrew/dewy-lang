# Milestone 22: refinement contracts and finite facts

Accepted design, 2026-10-20. Slices 1–6 are implemented.

## 1. Authority and observed starting point

`docs/GOALS.md` and ROADMAP's recorded decision govern: ordinary code retains runtime checks; rejecting unproven indices/divisors belongs to the strict lane. Older universal-rejection language in `no_traps.md` and the archived reference is superseded on this point. `$assert` and erased proofs still require static evidence in every lane. Refuted declared contracts remain errors; unknown executable obligations receive checks in ordinary code. For builtin index/divisor operations, ordinary code preserves its existing runtime-failure behavior even when failure is known; strict code rejects both unknown and refuted preconditions.

Use `finite_facts.md` as algorithmic guidance, not evidence that its former implementation exists here. `idiomatic_facts.md` motivates reusable contracts without authorizing arbitrary predicate plugins. Reviewed architecture §2 and review §3 correctly require identities and separate content/length/storage/sharing invalidation; full storage/inference/parallel refactoring is unnecessary first.

Observed at this HEAD: `types.jo` interns concrete descriptors and structurally compares inference-bearing types; `units.jo` demonstrates erased qualifiers. `dewy_parse.jo:dw_type` accepts fixed `length=N`, but rejects general refinement syntax. `expr.jo:check_intrinsic` immediately proves and empties `$assert` operands; `check.jo:prove_assertion` falls from `sa_*` into `ct_run`. Scratch probes confirm closed helper evaluation succeeds, while guards and successful `$runtime_assert` do not prove symbolic parameter assertions. These are current observations, unlike the older ladder's initial-HEAD results.

`isolation.jo` already solves demanded ambient-isolation SCCs, including hidden helper edges. It explicitly does **not** prove purity, argument nonmutation, or no panic. `lower.jo` separately maintains `safe_index`, `nonneg_locals`, `positive_writes`, and `fp_scan`/`fp_begin`; fixed paths cache pointers and sometimes uniqueness as well as lengths. Their contracts cannot collapse into one Boolean “safe.” `semantic_contracts.md` also requires mathematical-integer semantics independent of representation; numeric proofs must not inherit Sloppy's wrapping implementation `int`.

## 2. Canonical contracts, transient evidence

Add `refine.jo` for predicate canonicalization/instantiation and `facts.jo` for analysis. Add `TK.refined`, with `elem=base TypeId`, `st=PredicateId`, no additional `TypeInfo` field. Existing hash/equality already include kind, elem and st. Intern alpha-normalized predicates separately; flattening nested qualifiers and sorting/deduplicating conjuncts is sufficient canonicalization, without theorem-equivalence checking. Preserve pointer-fast equality for concrete types. Propagate `TF_HAS_VAR`, substitute/zonk predicates with their base, and never mutate an interned predicate.

Predicate terms are `Self`, formal ordinal, record-field ordinal, lexical declaration identity, and their field/length projections. References to another binder include its binder environment identity; source spelling and AST addresses never define equality. Source spans live in declaration-use metadata. Runtime versions, intervals and proof witnesses never enter type interning. Concrete generic substitution must resolve type-dependent projections before publication. Keep declared storage contracts separate from inferred current-value qualifiers; unification solves base-type shape, while implication checking discharges refinements. Dependent callable contracts use alpha-normalized formal slots in a `ContractId` on `FnSig`; callable type identity must also include this contract, using a refined callable descriptor, without reusing `fn_.st` (already callable labels).

`representation_type` erases refinement wrappers while retaining units' dimension checks; layout, managedness, boxing and ABI delegate to the base. Dispatch selects the base overload, then checks obligations; refinements do not drive overload search. Ordinary inferred literals/lengths remain facts, not permanent assignment types. Existing fixed-array `length=N` representation stays fixed; inequalities qualify dynamic arrays. Aliases and nested `array<positive>` preserve logical qualifiers.

Accepted contract atoms: integer bounds, nonzero/disequality, comparisons between named scalar/length terms, conjunctions, ordered chains, literal-range membership, field projections and existing tag tests. Support lambda, own-parameter/member and partial-operator spellings from the archived grammar, plus result-arm fact blocks. Canonical numeric atoms are intervals and `x-y>=c`; equality is two directions. Do not admit arbitrary arithmetic in annotation bounds. Assertions/guards additionally recognize checked affine addition/subtraction and literal scaling, including small weighted rows selected from source. This distinguishes accepted contract syntax from incomplete entailment.

Reject impure annotation expressions, opaque predicates, quantifiers, nonlinear products, arbitrary calls and cyclic dependent declarations with the offending span. Pure calls in guards/assertions contribute verified contracts, never presumed meanings. Unverified extern declarations export no checked theorem; reviewed intrinsic contracts use resolved binding identity, not pathname privilege. Deferred: sortedness, collection-wide correlations, abstract user predicates and trusted validators. Unrecognized executable assertions stay unknown. Numeric normalization uses resolved builtin identity, checked coefficient arithmetic, signed/unsigned domains and operation widths. Fixed-width expressions transfer mathematically; storage narrowing is a separate obligation. Explicit overflow policy operations retain their modular or saturating meaning. Length caps are target-indexed evidence, granted only where runtime representation guarantees them. Do not encode the archived unrestricted `addr`-addition claim as arithmetic closure.

## 3. Transfer at evaluation points

Use compact per-instance arrays over the existing checked tree, with structured edges for branches, short circuits, returns, breaks and continues. No second expression IR. `PointId` identifies evaluation events; `PlaceId` identifies a declaration-root plus field, constant index, stable selector ValueId, or unknown projection. Promote `lpath`'s integer parent representation; normalize checker narrowing aliases and element aliases to underlying places.

A state maps places to current **ValueIds**, including separate length terms. Every read captures an immutable evaluated value; writes create a new current value. Snapshot relations survive source writes when all their other endpoints survive. Storage and sharing epochs are independent prerequisites for pointer hoisting and uniqueness. Facts carry witness IDs and dependency versions; publication keys include instance/body revision, target and summary generation.

Transfer follows actual lowering order, including named arguments (`call_eval_order`), receiver, selectors, defaults, hooks and cleanup. In `use(a[i], mutate(@a))`, freeze the first argument and its facts before the second runs. Evaluate an assignment's RHS and target components in the compiler's specified order, check the captured replacement, then install it; never replay expressions. Constructor defaults see private earlier-field snapshots; publish destination facts before retiring temporaries. Successive actuals may invalidate links to current places while preserving evaluated arguments.

Invalidate by overlap:

- Replacement kills the place and descendants, including lengths/storage. Scalar or selector writes retire dependent selected routes.
- Element writes kill possibly equal selected elements; unequal selector identities alone prove nothing. Require established disequality to preserve another selection. Containing lengths survive; replacing an array-valued element kills its own length.
- Resize creates new length/content/storage versions. Known push/pop/clear transfer length equations and surviving bounds; growth may preserve indices but never element identity after insertion/removal. Reserve/detach/data access may retain lengths while invalidating storage. Copies retain value facts but invalidate uniqueness assumptions.
- `@` aliases/shared captures map to overlapping roots. Unknown raw provenance kills all potentially exposed regions; unsupported aliasing yields unknown rather than a guessed root.

Extend checked summaries with capped may-write/resize/expose regions and witnesses, initially conservatively killing every mutable actual plus exposed ambient roots. Isolation can exclude ambient interference only; it cannot exempt actuals. Unknown callbacks/externs are top over reachable regions. Include implicit equality/hash/format/drop calls and callback captures. Region sets saturate to “any reachable,” not unsound truncation. SCCs publish only after settlement; declarations with checked contracts support modular recursion, but compilation succeeds only after every body obligation is validated or checked. New or changed bodies invalidate dependent publications.

At joins, allocate merge ValueIds for current places; rename each predecessor into that frame and retain only universally supported facts, joining intervals by hull. Unreachable edges contribute nothing. Do not retain branch-local IDs or enumerate all term pairs. Repeated declarations have iteration-local identities; dominating scalar snapshots differ from current storage.

Loops start with entry and backedge joins, including condition effects, zero trips, all continues and outward exits. Select candidates from entry facts, guards and assertion syntax, never assume an assertion's desired truth. Validate initiation and preservation on every advancing edge. Widen after two passes; permit at most eight widening and three narrowing passes with 4,096 speculative transfer steps shared by a loop nest. On exhaustion restart unstable components at top and perform final validation; no speculative proof survives. Iterator range evidence must describe the captured range and current source separately.

Bound each active state to 256 tracked terms, 256 relational rows, 32 weighted rows, and eight incident rows per tracked term; additional inference stays unknown. Sparse state deltas or bounded copies avoid copying a function-wide locals vector at every branch; ValueId/event tables themselves grow linearly with the body. Queries visit at most 128 expression nodes, 32 terms and 256 graph edges, using bounded weighted path relaxation without all-pairs closure. Cache answers within one state revision. Linear-ish cost follows from constant budgets per event/query; state caps bound joins and nested-loop speculation. Contract evaluation itself is never omitted when inference capacity runs out. The implementation API is `capture(expr,state)`, `transfer(event,state)`, `assume(branch,value,state)`, `entails(predicate,state)` and `join(edges)`; queries never mutate evidence. Store compact per-point obligation answers for lowering rather than retaining every state.

## 4. Executable boundaries and assertions

Record `Obligation(predicate, captured operands, point, origin, policy)` during checking. Analysis returns proven, refuted, or unknown with a reason. Internal policy is `RuntimeAllowed` versus `RequireStatic`, passed through module/function checking configuration; tests may set it through an internal harness. This adds no strict-lane syntax. Strict acceptance also requires final implementation/callee panic-cost accounting: an ordinary callee with fallback checks does not become no-panic because its returned facts are valid.

Refined arguments are checked after evaluating all actuals, immediately before invocation, against **captured** by-value arguments and current place arguments. Callee entry receives facts only for the values actually checked. By-value postconditions refer to entry snapshots; private parameter mutation must not turn a promise about the evaluated caller argument into a promise about its replacement. Place postconditions refer to post-call versions. Save results before cleanup, run defers, then verify postconditions against the final observable state. At the caller apply may-effects first, then install verified result/arm facts. Result narrowing activates conditional facts only while their result and dependencies remain valid. Keep existing union narrowing for member resolution; bind its synthetic aliases to the same semantic values and verify tag evidence at the point of use. This pass does not retroactively typecheck an arbitrary previously ill-typed access.

Fields, annotated locals, element types, structural conversions and generated constructors check every construction/store, including defaults and zero initialization. Missing initialization cannot mint `positive`. Validate a tentative updated aggregate before committing a dependent sibling-field write; reverse dependency lists find affected contracts. Lexical dependent annotations follow the archive's stable-bound restriction: reject mutable external dependencies rather than silently changing their meaning. Whole-record replacement checks the entire invariant.

Do not erase invariants through mutable access: refined storage cannot pass to an unrefined `@` formal or raw mutable view. Require an equivalent instantiated storage contract and stable dependencies, conservatively rejecting overlap/exposure until supported. Full-root record parameters retain field contracts. Checking only after a weaker callee returns is insufficient because callbacks could observe invalid intermediate fields. Immutable value forgetting is safe; mutable containers remain invariant under element-contract changes.

Generic templates retain binder contracts; concrete instances substitute once and analyze once. Calls never specialize on current intervals. Callable conversion must establish target preconditions imply implementation preconditions, and implementation guarantees imply target guarantees; unknown implication rejects conversion, avoiding runtime wrapper synthesis initially.

For unknown executable obligations, emit a dominating runtime check before store/call/access, or after return cleanup; no success fact precedes the check. Evaluate operands once. Refuted declared refinements fail compilation; primitive-operation failures follow the lane policy above. Division tracks zero and separate machine-lowering hazards (including signed minimum divided by -1), preserving specified floor/wrapping semantics. Index checks additionally validate pointer/representation requirements before dereferencing.

Retain the constant `sa_*` fast path and general `comptime.jo` evaluation for closed compile-time requests. Symbolic `$assert` operands must survive `check_intrinsic`; queue them and query the fact state later. Never run `ct_run` on an open runtime value or convert proof-budget exhaustion into comptime execution. Compile-time execution remains allowed to be unbounded. Symbolic assertions must contain pure fact terms or checked pure calls; isolation alone cannot authorize erasure of a call. Proven assertions erase; unknown/refuted assertions error. `$runtime_assert` success applies the tested condition's surviving facts, with short-circuit effects and later operand mutation accounted for; messages do not establish evidence. Preserve existing failure reporting and reject proven-false assertions.

Checked `$proof` follows the archived subset: direct statement calls, pure fact-term arguments, acyclic proof dependencies, assertions/branches/bare returns/proof calls only; no loops, runtime calls, globals, defaults, place parameters or unsafe assumptions. Check preconditions and every normal-exit proposition before erasing definitions/calls. No runtime fallback is legal for erased arguments or bodies. Verify absence of emitted proof symbols/calls.

`$prototype` scope remains David's decision. Represent deferred executable obligations internally with origins; they may produce ordinary runtime checks, never static evidence or relaxed proofs. Keep the existing explicit unsupported-surface diagnostic until scope is settled. Program 09's checked helper is shippable independently; milestone 22's prototype surface remains explicitly OPEN.

## 5. Unknowns with witnesses

Return `UnknownReason` plus the smallest retained evidence chain: missing lower/upper bound, invalidation event, predecessor lacking evidence, unsupported operation, possible wrap, unsettled callee or budget exhaustion. Keep bounded predecessor/witness links and one tombstone per invalidated tracked route, not entire historical states. A consistent valuation satisfying known constraints but violating a requested condition can be shown as a **possible** witness; incomplete solving must never label it a real execution.

For program 07, strict mode should report at `xs[i]`: “index is not in bounds”; notes: `i=0`; `xs.length=0 after clear` (pointing to `clear`); “the earlier i<length fact described the pre-clear value.” For an unknown resizing call, say instead “cannot prove index”; show the established guard, the call/summary path invalidating length, and which bound remains missing. Ordinary mode retains its runtime check; adding `$assert` requests the same static diagnostic. Golden cases distinguish refuted, unknown, unsupported syntax and exhausted budget, including generic-instantiation and contract-declaration spans. Repair suggestions mention a current guard, stronger checked contract or explicit runtime assertion; `$assert` is never suggested as new evidence.

## 6. Cost budget: measured baseline, judged additions

**Judgment:** dormant overhead should be 0.5–2 M instructions (0.04–0.15% now; 0.13–0.5% of the 400 M target): demand flags set during existing checking, sparse obligations, no new body traversal/state allocation in functions without consumers. Before consolidation this synthetic has no explicit refinement consumers. After migration its ordinary loops must use a cheap interval/range mode during existing traversals, with full relational/loop search still demanded only by contracts, assertions or strict checking; the dormant estimate is conditional on that design, not free analysis of 181k nodes. Allow an initial **12–30 M** range (0.9–2.2% now, 3–7.5% of target), not a forecast for arbitrary predicates. Near-budget graphs/loops can cost more and must be measured separately. Discharge cheap obligations without graphs; allocate relational state on demand; free function scratch promptly.

Consolidation must replace walks: migrate `positive_bound`/`positive_writes`, `safe_index`, length snapshots and nonnegative facts to point queries. Feed `fp_begin` semantic length/index answers, but retain storage/escape/uniqueness checks; later share its effect event collection and remove duplicate `fp_scan` traversal only after equivalence tests. Never OR an invalidated new proof with an unchecked legacy result.

Implementation gates: seven alternating baseline/candidate fresh single-worker samples after warmup, identical root/library counts, default and release kernel instructions within +3%; dormant aggregate increase ≤1% against the fixed reference, not compounded per slice. Profile active refinements separately; savings from removed scans must be measured, not booked in advance. Keep check-only/build answers identical. No repository tests or implementation changes were made this round.

### Invariants and brands

- Invariants: types declare invariants; construction proves them (or checks
  them under `$runtime_checks`) and mutating methods re-establish them. Richer
  properties ("sorted", "validated") are brands minted only by trusted
  validators; later, user-defined validators via compile-time code. Public
  interfaces use written contracts; inferred facts stay private.

### Deferred

- Index-typed refinements: deferred until real code needs them.

### Partial operators (2026-10-23)

- Refinements prefer partial operators (decided 2026-10-23): where a refinement
  is a single comparison or test against the value, the idiomatic spelling is
  the reference's partial operator (`b:int64<(>=? a)>`), not a lambda
  (`b:int64<v => a <=? v>`); docs, examples, diagnostics and fix-its use it.
